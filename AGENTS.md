# Portfolio design guidance

Before making visual or UX changes, read:

- `docs/DESIGN_DOCTRINE.md`
- `docs/PORTFOLIO_PRODUCT_SPEC.md`
- `docs/CURRENT_DESIGN_STATE.md`

These documents are the source of truth for portfolio design work.

Design priorities, in order:

1. Help visitors understand Kai quickly.
2. Keep related information physically close.
3. Remove duplicated information.
4. Preserve Kai's handmade identity.
5. Prefer information density over decorative whitespace.
6. Do not introduce visual patterns merely because they are trendy.

For significant visual work:

1. Inspect the current rendered page.
2. State the intended changes and why.
3. Do not invent new visual motifs without explicit justification.
4. Inspect desktop and mobile after implementation.
5. Compare the result against the documented acceptance criteria.
